# مخطط قاعدة البيانات (Database Schema)

الجداول الأساسية:
1. `tickets`: البلاغات والأرقام المتسلسلة IT-2026-000XXX
2. `branches`: الفروع والشركات
3. `categories`: أقسام الصيانة
4. `users`: الفنيون والمديرون
5. `ticket_comments`: الملاحظات العامة والداخلية
6. `ticket_history`: سجل الحركات والتدقيق
7. `system_settings`: الإعدادات العامة
