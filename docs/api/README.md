# توثيق واجهات برمجة التطبيقات (API Documentation)

- `GET /api/core/health/`: فحص الحالة
- `GET /api/core/settings/`: إعدادات المنظومة
- `GET /api/public/config`: إعدادات الفروع والأنواع
- `POST /api/public/tickets`: إنشاء بلاغ صيانة
- `POST /api/public/tickets/track`: الاستعلام عن بلاغ (مطابقة رقم البلاغ والرقم الوظيفي)
- `POST /api/auth/login`: تسجيل دخول الفنيين
