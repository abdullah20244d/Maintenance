# معمارية النظام (System Architecture)

نظام إدارة بلاغات الدعم الفني والصيانة مصمم وفق معمارية الوحدات المعيارية النظيفة (Modular Clean Architecture):

1. **config/**: إعدادات البيئة (التطوير، الاختبار، الإنتاج، والتشغيل المكتبي).
2. **apps/core/**: الخدمات الأساسية المشتركة، سجل التدقيق، إدارة الإعدادات، واستراتيجية المستودعات (Repository Pattern).
3. **apps/accounts/**: إدارة المستخدمين، المصادقة، الأدوار الفنية والصلاحيات.
4. **apps/modules/**: وحدات الأعمال القابلة للتوسعة والإضافة.
5. **templates/** و **static/**: قوالب واجهة المستخدم والمكونات القابلة لإعادة الاستخدام.
