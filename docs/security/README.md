# سياسة وضوابط الأمان (Security Policy)

1. **التحقق المشروط من البلاغ**: لا تظهر تفاصيل البلاغ إلا بعد المطابقة الصارمة بين رقم Ticket والرقم الوظيفي.
2. **عزل الملاحظات الداخلية**: الملاحظات الفنية الداخلية محجوبة تماماً عن موظفي الفروع في الاستعلامات العامة.
3. **تشفير كلمات المرور**: تجزئة بـ bcryptjs / PBKDF2.
4. **تحديد معدل الطلبات**: حماية من محاولات التخمين والاختراق.
