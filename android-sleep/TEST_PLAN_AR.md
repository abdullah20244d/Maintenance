# خطة القبول وحالة التحقق

نجحت اختبارات الحسابات وAndroid Lint والبناء والتوقيع. نجح اختبار محاكي API 35 للتثبيت والواجهة ومنح إذن المنبّه وإطلاقه مع إطفاء الشاشة ودون اتصال وإيقافه من الواجهة، دون انهيار للتطبيق. بقية الحالات أدناه، خصوصًا توفير الطاقة وإعادة التشغيل والغفوة وS24 Ultra الفعلي، لم تُختبر. راجع VALIDATION.json وروابط التنفيذ فيه.

| الحالة | النتيجة المطلوبة |
|---|---|
| بناء المصدر | نجاح testDebugUnitTest وlintDebug وassembleDebug |
| أول تشغيل دون أذونات | واجهة وسجل متاحان؛ منع التفعيل الدقيق مع شرح |
| منح/رفض المنبّه الدقيق | تحقق الحالة؛ لا ادعاء بتفعيل منبّه لم ينجح |
| اختبار 15 ثانية وشاشة مفتوحة | إشعار وصوت تصاعدي واهتزاز حسب التفضيل |
| شاشة مقفلة وAlways On Display | رنين في الموعد، شاشة أو إشعار حسب الإذن |
| رفض الإشعارات أو شاشة الإيقاظ | حالة واضحة في الجاهزية، اختبار الصوت فعليًا؛ لا ضمان لواجهة الإيقاف |
| منع قناة الإشعار | اكتشاف المنع من إعدادات النظام واختبار العرض بعد إعادة السماح |
| صوت المنبّه صفر/عدم الإزعاج | عرض مستوى الصوت وضبط السماح بالمنبّهات ثم إعادة الاختبار |
| وضع الطيران ودون Wi-Fi | نفس الإيقاظ المحلي |
| توفير الطاقة وDoze لساعة | تحقق الموعد والصوت على الجهاز؛ لا يكفي اختبار 15 ثانية |
| خروج من التطبيق/إزالة من الأخيرة | تحقق أن المنبّه لا يعتمد على بقاء الواجهة |
| إعادة تشغيل ثم فتح القفل | إعادة جدولة الموعد القادم دون تشغيل صوت من مستقبل الإقلاع |
| تغيير المنطقة/الوقت | يبقى موعد الجدول بالتوقيت المحلي الجديد؛ لا رنين قديم متأخر أكثر من 10 دقائق |
| منع إذن المنبّه ثم منحه | إعادة جدولة المنبّه المحفوظ إن كان مفعّلًا؛ تأكيده من داخل التطبيق |
| غفوة وإيقاف من الإشعار | إيقاف الصوت/الاهتزاز؛ الغفوة في مدتها؛ استمرار الجدول الأسبوعي |
| إيقاف تلقائي | ينتهي الرنين بعد 10 دقائق وتحرير الموارد |
| إيقاف قسري/بطارية فارغة | توثيق حدود النظام؛ افتح التطبيق وأعد الاختبار |
| سجل عبر منتصف الليل | مدة صحيحة بعد طرح اليقظة، وعدم اعتبار وقت الفراش بداية مؤكدة |
| بيانات غير صالحة | رفض نهاية قبل البداية/يقظة أطول من النوم/تواريخ مستقبلية |
| تصحيح سجل | استبدال السجل السابق وعدم تكراره |
| تصدير وإلغاء التصدير | ملف JSON صالح دون تعطل؛ لا ملفات عند إلغاء الاختيار |
| حذف جميع البيانات | تأكيد ثم حذف وإلغاء جميع المنبّهات والاختبار والغفوة |
| مصدر ساعة غائب | لا بيانات وهمية ولا إيقاظ مبكر، حتى مع اختيار نافذة |

أجرِ اختبارين ليليين على الأقل مع منبّه احتياطي وسجّل إصدار Android وOne UI وإعدادات البطارية وتأخر الإيقاظ وأي فشل. نجاح هذه الاختبارات ليس اعتمادًا طبيًا أو ضمانًا مطلقًا.
