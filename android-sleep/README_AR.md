# نوم متوازن — Android 0.1.0

مشروع تطبيق Android أصلي بلغة Kotlin وJetpack Compose، بواجهة عربية RTL داكنة مرنة للشاشات الكبيرة ومنها Galaxy S24 Ultra. هذه نسخة مصدر أولية غير مجمّعة وغير مختبرة على جهاز. ليست جهازًا طبيًا ولا تقيس مراحل النوم.

## ما تم تنفيذه في المصدر

- منبّه محلي دقيق بأيام أسبوعية، موعد واحد للأيام المختارة؛ يعمل دون إنترنت أو حساب.
- صوت منبّه النظام مع نغمة WAV مضمّنة بديلة عند تعذّر فتحه، بتدرج الشدة، اهتزاز اختياري، غفوة 1–15 دقيقة، إيقاف بعد عشر دقائق.
- خدمة تشغيل صوت أمامية وإشعار بإيقاف/غفوة وشاشة إيقاظ وفق صلاحيات النظام.
- إعادة جدولة الموعد التالي بعد الرنين، وإعادة الجدولة بعد إعادة التشغيل (بعد فتح قفل المستخدم) أو تغيير الوقت والمنطقة أو منح الإذن.
- جلسة «سأنام الآن»، سجل صباحي يدوي قابل للتصحيح يشمل زمن الاستغراق واليقظة والنشاط والنعاس والقيلولة والكافيين.
- مدة مستهدفة واستغراق قابلان للضبط؛ بعد 3 سجلات يستخدم اقتراح الفراش وسيط آخر 14 زمن استغراق. هذا تخصيص حسابي بسيط وليس نموذج ذكاء اصطناعي طبيًا.
- تقرير آخر 7 أيام: متوسط مدة النوم والنشاط والنعاس وتشتت موعد الاستيقاظ مع معالجة عبور منتصف الليل.
- قراءة حالة إذن المنبّه والإشعارات وشاشة الإيقاظ وصوت المنبّه وإرشاد لقيود بطارية Samsung.
- تصدير السجل بصيغة JSON وحذف البيانات والمنبّهات بعد التأكيد.
- تخزين محلي في مساحة التطبيق الخاصة، دون إذن إنترنت أو ميكروفون أو بيانات صحية؛ النسخ الاحتياطي التلقائي معطل. التخزين يستخدم حماية مساحة التطبيق وتشفير الجهاز، دون طبقة تشفير مستقلة داخل التطبيق.

## الميزات المؤجلة بوضوح

- لا يوجد Health Connect أو Samsung Health أو BLE أو قراءة من Galaxy Watch/Ring في هذه النسخة.
- خيار وجود ساعة يحفظ تفضيلًا فقط، ولا يمثل اتصالًا ناجحًا.
- نافذة الإيقاظ تحفظ التفضيل فقط وتعمل حاليًا بالموعد النهائي الثابت. لا يوجد إيقاظ مبكر ولا خوارزمية مراحل نوم ولا نسب ثقة.
- لا توجد تسجيلات صوتية أو استشعار نوم أو تحليل شخير أو قياس نبض/أكسجين.
- لا يوجد جدول مناوبات متعدد أو نغمات عشوائية أو تذكير مسائي تلقائي. يمكن تغيير أيام الجدول يدويًا.
- التقرير لا يشخّص اضطرابًا ولا يثبت سبب تغير النشاط. لا توجد رسوم مراحل نوم مولدة.

## طريقة بناء APK على Windows 11

المتطلبات: إنترنت لتنزيل الاعتماديات، Android Studio يدعم Android Gradle Plugin 8.9.2، وJDK 17، وAndroid SDK Platform 35، وGradle 8.11.1. لا تتطلب النسخة حساب مطوّر أو اشتراك API.

1. فك الضغط، وافتح مجلد BalancedSleep الذي يحتوي settings.gradle.kts في Android Studio.
2. من SDK Manager ثبّت Android SDK Platform 35 وأدوات البناء المقترحة، ومن إعدادات Gradle اختر JDK 17.
3. لم يُضمّن Gradle Wrapper binary؛ لا تنفذ gradlew وهو غير موجود. ثبّت Gradle 8.11.1 من موقعه الرسمي وأضف bin إلى PATH، ثم افتح Terminal داخل مجلد المشروع.
4. نفّذ `gradle wrapper --gradle-version 8.11.1` لإنشاء Wrapper، ثم `./gradlew testDebugUnitTest lintDebug assembleDebug` (على PowerShell استخدم `.\gradlew.bat testDebugUnitTest lintDebug assembleDebug`).
5. إذا لم يُنشئ Android Studio ملف local.properties، أنشئه بقيمة sdk.dir الصحيحة لمسار SDK على حاسوبك؛ لا تشارك هذا الملف.
6. الناتج المتوقع: app/build/outputs/apk/debug/app-debug.apk. هذا APK تجريبي موقّع بمفتاح debug الذي ينشئه حاسوبك، وليس إصدار متجر.
7. انقل الملف لهاتفك وثبّته بعد السماح المؤقت بالتثبيت من المصدر الذي اخترته. أو صِل الهاتف عبر USB مع تفعيل خيارات المطوّر وتصحيح USB واضغط Run في Android Studio.

بديل البناء السحابي: ارفع محتويات المشروع إلى مستودع GitHub خاص بك بحيث يكون settings.gradle.kts في جذر المستودع. افتح Actions ثم Build Android APK ثم Run workflow، وبعد نجاح الاختبارات والبناء نزّل balanced-sleep-debug-apk من Artifacts. لم تُنفذ هذه العملية ولم يُرفع أي مستودع بالنيابة عنك. تعتمد الإتاحة والتكلفة على حساب GitHub وحدوده. حافظ على مفتاح توقيع ثابت عند الحاجة لتحديث النسخ دون حذف بياناتها؛ توقيع debug على منصات البناء المختلفة قد يتغير.

## الإعداد على S24 Ultra

1. افتح المنبّه واضبط العمر (النسخة للبالغين)، الموعد، الأيام، هدف النوم، الاستغراق، الاهتزاز والغفوة.
2. من جاهزية الإيقاظ اسمح بالمنبّهات الدقيقة، ثم فعّل المنبّه واحفظ. منح الصلاحية وحده لا يفعّل منبّهًا جديدًا.
3. اسمح بالإشعارات وشاشة الإيقاظ عند الطلب؛ افحص أيضًا قناة «منبّه الاستيقاظ» من إعدادات إشعارات التطبيق. قناة منخفضة الأهمية أو محظورة قد تمنع ظهور الشاشة حتى مع إذن عام.
4. من إعدادات بطارية التطبيق اختر الوضع غير المقيّد إذا توفر، وافحص قائمة تطبيقات السكون/السكون العميق في Samsung. تختلف التسميات بين إصدارات One UI.
5. ارفع صوت المنبّه من أصوات النظام، وتحقق أن وضع عدم الإزعاج يسمح بالمنبّهات. لا يعتمد التطبيق على صوت الوسائط.
6. نفّذ اختبار 15 ثانية، ثم اقفل الشاشة. جرّب الإيقاف والغفوة من الشاشة والإشعار. كرر الاختبار مع فصل الإنترنت.
7. ابدأ جلسة النوم ليلًا، وصحّح البداية التقديرية وسجّل الاستيقاظ وتقييمك صباحًا. يمكن تعديل السجلات السابقة من السجل. التواريخ يدوية بأرقام إنجليزية وتوقيت الهاتف الحالي؛ الأوقات الملتبسة أثناء انتقال التوقيت الصيفي مرفوضة.

لا يستطيع التطبيق تشغيل الهاتف المغلق أو تجاوز نفاد البطارية أو ضمان عمله بعد Force stop. بعد إيقاف قسري افتحه وأعد الاختبار. إعادة التشغيل تتطلب فتح القفل أول مرة للوصول إلى التخزين. لا نضمن الأداء على One UI أو Android 17 قبل اختبار فعلي. استخدم منبّه الهاتف الاحتياطي أثناء تقييم هذه النسخة الأولية.

## التحقق الفعلي وحالة الاختبار

البيئة التي أُنشئ فيها المشروع لا تحتوي Android SDK أو Gradle أو مترجم Kotlin أو محاكيًا، وفشل الوصول إلى تنزيل أدوات Android/Gradle بسبب قيود الشبكة. لذلك **لم يُبنَ APK، ولم تُنفّذ اختبارات Kotlin أو Android Lint، ولم يُختبر الرنين على هاتف**. لا يُعد الفحص البنيوي للكود دليلًا على نجاح التجميع أو موثوقية الإيقاظ.

أُضيفت اختبارات JUnit ذات معنى للحسابات: اختيار اليوم التالي، تعطيل الجدول، احتساب وقت الفراش عبر منتصف الليل، انتقال التوقيت الصيفي، طرح اليقظة الليلية، وسيط الاستغراق، وانتظام الاستيقاظ حول منتصف الليل. تنفّذها أوامر البناء أو GitHub Actions.

راجع TEST_PLAN_AR.md قبل الاعتماد عليه، وROADMAP_AR.md لتوسعات الساعة والنافذة الذكية.
